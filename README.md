# Qué modelo de Claude usar

Guía de tres páginas para elegir modelo de Claude según lo que estés haciendo: **Opus para pensar, Sonnet para hacer, Haiku para lo rápido**.

- En el trabajo de cada día (analizar, redactar, buscar, pulir).
- Al construir una aplicación o una automatización (planificar, construir, revisar, cambios pequeños).
- Cuatro reglas para no equivocarse y una frase para pedir un cambio pequeño con seguridad.
